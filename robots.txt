# NOTES FOR IMPLEMENTATION
# ─────────────────────────────────────────────────────────────────────────
#
# 1. Google-Extended Behavior:
#    - Respects "Allow" directives for homepage content
#    - Blocked from /courses and all payment/enrollment pages
#    - Crawl-delay of 2 seconds to prevent overloading
#
# 2. Gemini API Context:
#    - The Python script (gemini_homepage_indexer.py) enforces strict
#      URL validation at the application level
#    - robots.txt provides a second layer of defense
#    - Together they ensure Gemini only sees homepage content
#
# 3. Course Content Protection:
#    - /courses, /course.html, /enrol explicitly disallowed
#    - Payment routes (/checkout, /payment, /cart) blocked
#    - User data (/user, /dashboard) protected
#    - Admin routes (/admin, /api) blocked
#
# 4. Testing Your robots.txt:
#    - Google Search Console: https://search.google.com/search-console
#    - Test URL blocking: robots.txt Tester tool
#    - Validate syntax: https://www.robotstxt.org/robotstxt.html
#
# 5. Deployment:
#    - Place this file in your web root: /robots.txt
#    - Verify it's accessible: https://nuancedco.com/robots.txt
#    - Wait 24-48 hours for full propagation with crawlers
